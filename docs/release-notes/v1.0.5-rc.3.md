# nexPDF v1.0.5-rc.3

## 中文

本轮验收修复打开及另存后标题栏无法显示未保存标记的问题，并为搜索框和七项水印参数补齐随中英文切换的无障碍名称。小数缩放截图测试改为验证实际 DPR 和取整后的物理像素尺寸。

本地核心回归 31 项通过，实际 100%/125%/150%/175%/200% 缩放各通过 10 项 UI 检查；50 轮共 5000 页稳定性、15 页复杂语料和 10 份 Poppler 独立输出检查通过。详见[本轮验收记录](https://github.com/YDLuo-1/nexPDF/blob/v1.0.5-rc.3/docs/acceptance-20261104.md)及其中的测量边界。依赖文档同时纠正了公开 Windows 包与本地完整 Qt 部署目录的区别。

仍是预发行版。原生输入法/驱动打印交互被中止，未计为通过；实体打印、macOS 真机、混合 DPI 切换和完整读屏验收仍待完成，不据此升级为稳定 Latest。

## English

Restore the native unsaved marker after opening and Save As, and expose localized accessible names for search and seven watermark parameters. Fractional-DPI screenshot checks now verify actual DPR and rounded physical pixels.

Local acceptance passed 31 core checks, ten UI checks at each of five actual DPRs (1–2), 5000 pages across 50 open/render/close cycles, a 15-page mixed corpus, and ten independent Poppler output checks. See the [acceptance record](https://github.com/YDLuo-1/nexPDF/blob/v1.0.5-rc.3/docs/acceptance-20261104.md) for raw data and limits. The dependency inventory now distinguishes the published Windows package from a full local Qt staging directory.

This remains a prerelease. Native IME/driver-printing interaction was interrupted and is not accepted; physical printing, macOS hardware, mixed-monitor transitions and full screen-reader acceptance remain open. Stable Latest is unchanged.
