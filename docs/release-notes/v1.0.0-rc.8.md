# nexPDF v1.0.0-rc.8

## 中文

本候选版修复三处查看与编辑体验问题，来自人工验收反馈：

- 搜索结果现在在页面上以黄色高亮显示，当前命中项为橙色；重复按回车在命中项之间循环跳转，视图自动滚动到当前命中位置，状态栏显示"第 k / N 处"。
- 修复"添加文字"渲染为大黑块的问题：MuPDF 的 FreeText 注释把 /C 颜色用作文本框背景色，此前背景与文字同为黑色导致整块变黑。现在文本框为白色背景、文字使用所选颜色。
- "添加文字"与"添加图片"不再静默落到页面固定位置：输入内容或选择图片后，在页面上拖动一个矩形决定放置位置与大小，状态栏会提示当前操作。

这是候选版，不是 Latest 正式版。完整人工界面检查和性能验收仍是正式 v1.0.0 的前置门槛。发布包不含代码签名，Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告；下载后请核对 GitHub 显示的 SHA-256 摘要，并只处理您拥有权利或已获授权的 PDF。

## English

This release candidate fixes three viewing and editing issues reported during manual acceptance:

- Search results are now highlighted on the page in yellow, with the active match in orange; pressing Enter repeatedly cycles through matches while the view scrolls to the active one, and the status bar shows "Match k of N".
- Fixed "Add text" rendering as a large black block: MuPDF's FreeText annotation uses the /C color as the text-box background, and the background previously matched the text color. The box now has a white background while the text uses the chosen color.
- "Add text" and "Add image" no longer drop content at a fixed page location: after entering text or choosing an image, drag a rectangle on the page to set the placement and size, guided by a status-bar hint.

This is a release candidate, not the Latest production release. Full manual UI checks and performance acceptance remain gates for v1.0.0. Packages are not code-signed; Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub after downloading, and only process PDFs you own or are authorized to modify.
