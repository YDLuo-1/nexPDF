# nexPDF v1.0.0-rc.4

## 中文

这是首个公开可下载的发布候选版，供安装、兼容性和真实 PDF 测试。RC.4 补充了 macOS Universal 包超过 80 MiB 目标时所需的实测组成分析，并让流水线明确输出各资产体积。RC.3 已成功生成全部平台资产，但在缺少组成分析时按门槛停止，因此没有发布不完整的 GitHub Release；RC.1 和 RC.2 同样未产生 Release。

本版本包含连续 PDF 查看、缩略图、搜索与文字选择；AES-128/AES-256 加密和正确密码解密；页面与批注实用编辑；两阶段永久涂黑；可精确移除的 nexPDF 文字/图片水印及外部水印候选审查；MuPDF journal 撤销/重做和校验后原子保存。

安全加固：加密输出拒绝空用户密码和空所有者密码，并分别确认两类密码；允许两个密码相同，但会提示部分阅读器可能优先按用户身份打开，从而影响所有者权限操作；临时密码缓冲区和会话密码缓存在释放时覆盖清理。文档工作线程按 Qt 推荐的延迟删除模式安全销毁。

macOS Universal DMG 的 RC.3 实测为 82.730 MiB，超过 80 MiB 目标 2.730 MiB，主要来自包含 arm64/x86_64 与静态 MuPDF 的 82.450 MiB 主程序以及 Universal Qt 框架。没有删除中文或 CJK 支持；完整报告见仓库中的 `docs/package-size-analysis.md`。

这是候选版，不是 Latest 正式版。发布流水线会在 Windows x64、Linux x86_64 和 macOS Universal 上重新编译、测试，并通过 qpdf 与 Poppler 独立校验后才生成资产；完整人工界面检查和性能验收仍是正式 v1.0.0 的前置门槛。

发布包不含代码签名。Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告。请先核对 `SHA256SUMS`，保留原始 PDF 备份，并用独立工具验证重要输出。去水印功能仅限您拥有权利或已获授权的文件。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

This is the first publicly downloadable release candidate for installation, compatibility, and real-world PDF testing. RC.4 adds the measured composition analysis required when the macOS Universal package exceeds the 80 MiB target, and the pipeline now prints every package size. RC.3 generated all platform assets but correctly stopped before publication because the analysis was missing, so it produced no incomplete GitHub Release. RC.1 and RC.2 likewise produced no Release.

This version includes continuous PDF viewing, thumbnails, search and text selection; AES-128/AES-256 encryption and correct-password decryption; practical page and annotation editing; two-stage permanent redaction; exactly removable nexPDF text/image watermarks plus reviewed external candidates; MuPDF-journal undo/redo and validated atomic saving.

Security hardening: encrypted output rejects empty user and owner passwords and confirms both credentials separately; matching passwords remain supported, with a warning that some readers may open with user privileges first and therefore restrict owner-level operations; temporary and session password buffers are overwritten when released. The document worker object follows Qt's deferred-deletion pattern during thread shutdown.

The RC.3 macOS Universal DMG measured 82.730 MiB, 2.730 MiB above the 80 MiB target. The main contributors are the 82.450 MiB executable containing arm64/x86_64 code and static MuPDF, followed by the Universal Qt frameworks. Chinese and CJK support were not removed; see `docs/package-size-analysis.md` in the repository.

This is a release candidate, not the Latest production release. The release pipeline rebuilds and tests on Windows x64, Linux x86_64, and macOS Universal, then performs independent qpdf and Poppler validation before publishing assets. Full manual UI checks and performance acceptance remain gates for the final v1.0.0 release.

Packages are not code-signed. Windows SmartScreen and macOS Gatekeeper may warn. Verify `SHA256SUMS`, keep the original PDF, and independently validate important output. Remove watermarks only from files you own or are authorized to modify.
