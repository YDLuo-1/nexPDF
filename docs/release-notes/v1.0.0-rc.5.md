# nexPDF v1.0.0-rc.5

## 中文

本候选版整理了发布和本地项目目录：Release 只保留 Windows 便携 ZIP、Windows 安装 EXE、Linux AppImage、macOS Universal DMG 和包含 MuPDF 对应源码的完整源码包。SBOM、包体报告和独立 `SHA256SUMS` 不再作为 Release 附件；GitHub 会直接显示每个附件的 SHA-256 摘要，包体分析仍保留在仓库和 CI 中。

同时清理了可再生的构建、验证、审计和发布目录，并补充 CMake、Ninja、原生二进制和崩溃转储的 `.gitignore` 规则。源码、测试、文档、图标和 MuPDF 子模块未删除。

这是候选版，不是 Latest 正式版。完整人工界面检查和性能验收仍是正式 v1.0.0 的前置门槛。发布包不含代码签名，Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告；下载后请核对 GitHub 显示的 SHA-256 摘要，并只处理您拥有权利或已获授权的 PDF。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

This release candidate tidies the release and local project layout. Release assets are limited to the Windows portable ZIP, Windows setup EXE, Linux AppImage, macOS Universal DMG, and the complete corresponding-source archive containing MuPDF. The SBOM, package-size reports, and standalone `SHA256SUMS` are no longer uploaded as Release assets; GitHub displays a SHA-256 digest for every asset, while package analysis remains in the repository and CI.

Reproducible build, validation, audit, and distribution directories were removed locally, and `.gitignore` now covers generated CMake, Ninja, native binaries, and crash dumps. Source, tests, documentation, icons, and the MuPDF submodule were preserved.

This is a release candidate, not the Latest production release. Full manual UI checks and performance acceptance remain gates for v1.0.0. Packages are not code-signed; Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub after downloading, and only process PDFs you own or are authorized to modify.

The project is AGPL-3.0-or-later and was developed with substantial AI assistance. It is provided as-is, without warranty. nexPDF is not affiliated with similarly named products.
