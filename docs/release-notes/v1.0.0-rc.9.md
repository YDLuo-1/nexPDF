# nexPDF v1.0.0-rc.9

## 中文

本候选版带来一组查看与搜索的易用性改进：

- 按住 Ctrl 滚动鼠标滚轮即可缩放页面；视图菜单新增"适合宽度"（`Ctrl+2`），"实际大小"改为 `Ctrl+0`。
- `Ctrl+F` 直接聚焦搜索框并全选现有内容；搜索框清空后按回车会清除页面上的旧高亮。
- 按下 Esc 可取消待放置的"添加文字"/"添加图片"，不再必须拖拽完成。

这是候选版，不是 Latest 正式版。完整人工界面检查和性能验收仍是正式 v1.0.0 的前置门槛。发布包不含代码签名，Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告；下载后请核对 GitHub 显示的 SHA-256 摘要，并只处理您拥有权利或已获授权的 PDF。

## English

This release candidate ships a set of viewing and search usability improvements:

- Hold Ctrl and roll the mouse wheel to zoom the page; the View menu gains "Fit width" (`Ctrl+2`) and "Actual size" moves to `Ctrl+0`.
- `Ctrl+F` focuses the search box and selects its content; pressing Enter with an empty search box clears stale page highlights.
- Escape now cancels a pending "Add text"/"Add image" placement instead of forcing a drag.

This is a release candidate, not the Latest production release. Full manual UI checks and performance acceptance remain gates for v1.0.0. Packages are not code-signed; Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub after downloading, and only process PDFs you own or are authorized to modify.
