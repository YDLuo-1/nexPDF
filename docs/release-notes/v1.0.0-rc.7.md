# nexPDF v1.0.0-rc.7

## 中文

本候选版修复了高 DPI 屏幕上的页面模糊：主画布与缩略图现在按设备像素比渲染，150% 缩放下文字笔画恢复锐利，窗口拖到不同缩放率的显示器时自动按新密度重新渲染。

新增阅读位置记忆：按内容指纹（文件大小加首尾内容的 SHA-256）记住每个文档的最后阅读位置，文件改名或移动后依然有效；本机设置中只保存指纹和页码，不保存文件路径。视图菜单新增护眼模式，以乘法染色把页面底色调为柔和绿色，开关即时生效。Windows 安装器现在把 nexPDF 注册为按用户"打开方式"候选，并在系统"默认应用"设置中露出入口；不会抢占系统 `.pdf` 默认关联，卸载时完整清理这些注册项。README 新增双语设计取舍章节。

这是候选版，不是 Latest 正式版。完整人工界面检查和性能验收仍是正式 v1.0.0 的前置门槛。发布包不含代码签名，Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告；下载后请核对 GitHub 显示的 SHA-256 摘要，并只处理您拥有权利或已获授权的 PDF。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

This release candidate fixes blurry pages on high-DPI displays: the main canvas and thumbnails now render at the device pixel ratio, keeping text strokes sharp at 150% scaling, and re-render automatically at the new density when the window moves to a display with different scaling.

Reading positions are now remembered per document by content fingerprint (file size plus SHA-256 of the first and last 64 KiB), so renamed or moved files are still recognized; only the fingerprint and page numbers are stored locally, never file paths. The View menu gains an eye-care mode that multiplies the page background toward a soft green, applying instantly without re-rendering. The Windows installer now registers nexPDF as a per-user "Open with" candidate and a Default-apps entry without taking over the system `.pdf` default, and the uninstaller removes those registry entries. The README gains a bilingual design-decisions section.

This is a release candidate, not the Latest production release. Full manual UI checks and performance acceptance remain gates for v1.0.0. Packages are not code-signed; Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub after downloading, and only process PDFs you own or are authorized to modify.
