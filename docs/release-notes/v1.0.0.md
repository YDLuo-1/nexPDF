# nexPDF v1.0.0

## 中文

首个公开大版本：跨平台连续 PDF 查看、缩略图、搜索与文字选择；AES-128/AES-256 加密和正确密码解密；页面与批注实用编辑；两阶段永久涂黑；可精确移除的 nexPDF 文字/图片水印及外部水印候选审查；MuPDF journal 撤销/重做和校验后原子保存。

发布包不含代码签名。Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告。请先核对 `SHA256SUMS`，保留原始 PDF 备份，并用独立工具验证重要输出。去水印功能仅限您拥有权利或已获授权的文件。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

The first public major release: continuous PDF viewing, lazy thumbnails, search and text selection; AES-128/AES-256 encryption and correct-password decryption; practical page and annotation editing; two-stage permanent redaction; exactly removable nexPDF text/image watermarks plus reviewed external candidates; MuPDF-journal undo/redo and validated atomic saving.

Packages are not code-signed. Windows SmartScreen and macOS Gatekeeper may warn. Verify `SHA256SUMS`, keep the original PDF, and independently validate important output. Remove watermarks only from files you own or are authorized to modify.

The project is AGPL-3.0-or-later and was developed with substantial AI assistance. It is provided as-is, without warranty. nexPDF is not affiliated with similarly named products.
