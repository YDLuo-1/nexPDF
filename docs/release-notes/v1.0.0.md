# nexPDF v1.0.0

## 中文

首个公开大版本：跨平台连续 PDF 查看、缩略图、搜索与文字选择；AES-128/AES-256 加密和正确密码解密；页面与批注实用编辑；两阶段永久涂黑；可精确移除的 nexPDF 文字/图片水印及外部水印候选审查；MuPDF journal 撤销/重做和校验后原子保存。

安全加固：加密输出拒绝空用户/所有者密码，要求两类密码分别确认；相同密码仍允许，但会提示部分阅读器的所有者权限兼容风险；临时密码缓冲区和会话密码缓存在释放时覆盖清理。

发布包不含代码签名。Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告。下载附件后请核对 GitHub 显示的 SHA-256 摘要，保留原始 PDF 备份，并用独立工具验证重要输出。去水印功能仅限您拥有权利或已获授权的文件。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

The first public major release: continuous PDF viewing, lazy thumbnails, search and text selection; AES-128/AES-256 encryption and correct-password decryption; practical page and annotation editing; two-stage permanent redaction; exactly removable nexPDF text/image watermarks plus reviewed external candidates; MuPDF-journal undo/redo and validated atomic saving.

Security hardening: encrypted output rejects empty user/owner passwords and confirms both credentials separately; matching passwords remain supported with a reader-compatibility warning for owner privileges; temporary and session password buffers are overwritten when released.

Packages are not code-signed. Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub for the downloaded asset, keep the original PDF, and independently validate important output. Remove watermarks only from files you own or are authorized to modify.
