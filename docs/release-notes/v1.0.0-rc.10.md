# nexPDF v1.0.0-rc.10

## 中文

本候选版完成了一轮基于电脑控制的完整 Windows 界面验收，并修复验收中发现的一个问题：

- 编辑不再导致视图跳回文档顶部：revision 重建且页面布局不变时保持滚动位置。
- 验收覆盖：中文语料渲染、损坏 xref 自动修复打开、AES-256 密码解锁、可选内容图层、透明度混合、4000×3000 大图、搜索高亮与循环跳转、文字拖拽放置（白底黑字）、阅读位置跨会话恢复。

这是候选版，不是 Latest 正式版。干净虚拟机冒烟、macOS 与 Linux 实机抽查仍是正式 v1.0.0 的前置门槛。发布包不含代码签名，Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告；下载后请核对 GitHub 显示的 SHA-256 摘要，并只处理您拥有权利或已获授权的 PDF。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

This release candidate completes a full computer-use-driven Windows UI acceptance pass and fixes the one issue it found:

- Edits no longer reset the view: the scroll position is preserved when a revision rebuild keeps the same page layout.
- Acceptance covered: CJK corpus rendering, damaged-xref repair on open, AES-256 password unlock, optional-content layers, transparency blending, a 4000×3000 image, search highlight with match cycling, drag-to-place text (white box, dark text), and cross-session reading-position restore.

This is a release candidate, not the Latest production release. Clean-VM smoke tests and macOS/Linux spot checks remain gates for v1.0.0. Packages are not code-signed; Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub after downloading, and only process PDFs you own or are authorized to modify.

The project is AGPL-3.0-or-later and was developed with substantial AI assistance. It is provided as-is, without warranty. nexPDF is not affiliated with similarly named products.
