# nexPDF v1.0.3

## 中文

发布包不含代码签名。请核对 GitHub 显示的 SHA-256 摘要。AGPL-3.0-or-later，AI 辅助开发，按原样提供。

## English

- Local crash reporting: Windows writes a minidump (`crashes/`, at most five kept), Linux/macOS log the fatal signal; nothing is uploaded, and the privacy implications are documented in SECURITY.md. Verified locally end-to-end via the built-in `--crash-test` switch.
- Added an embedded-font corpus (KaiTi / XinWei subsets) with render verification, closing the last corpus line of the release checklist.
- macOS remains CI-verified only, as disclosed in v1.0.2.

Packages are not code-signed. Verify the SHA-256 digest shown by GitHub. AGPL-3.0-or-later, AI-assisted development, provided as-is.
