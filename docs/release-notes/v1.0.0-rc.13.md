# nexPDF v1.0.0-rc.13

## 中文

本候选版集中修复安全与正确性问题，并完成 Linux 实机验证：

- 移除 nexPDF 水印不再可能恢复涂黑前的页面快照：任何内容变更都会使已扫描候选失效，应用涂黑时会删除该快照。
- 打开失败或取消密码时保留原文档，不再出现"界面显示旧文档、会话已空"的脱节状态。
- 高亮改为半透明黄色、下划线与删除线改为红色，不再是不透明黑块。
- 已签名文档另存后可继续保存到该副本；PDF 权限按操作校验（编排/涂黑需 modify，批注需 annotate）。
- 密码参数改用独占深拷贝并在析构时清零的 `SecurePassword` 类型；POSIX 保存以 `0600` 创建临时文件、恢复目标权限并 fsync 文件与目录。
- 文本搜索分片交错执行：新搜索、编辑或关闭都会作废进行中的搜索，千页文档不再阻塞后续操作。
- Windows EXE/安装包补齐版本资源；macOS 应用包内附带许可证与第三方声明；另存后界面更新阅读位置键与标题；未打开文档时禁用文档动作。
- 翻译覆盖检查扩展到核心层并在 CI 运行（175 条零缺失）。正式版标签不再自动发布，需检查表完成后手动触发。
- 二进制包附带 LGPL-3.0（及 GPL-3.0）许可证原文，发布门槛强制检查；Linux 验证完成：rc.11 AppImage 在真实 Ubuntu 24.04 上通过 `--version` 与 WSLg 中文渲染检查。

这是候选版，不是 Latest 正式版。干净虚拟机冒烟与 macOS 实机抽查仍是正式 v1.0.0 的前置门槛。发布包不含代码签名，Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告；下载后请核对 GitHub 显示的 SHA-256 摘要，并只处理您拥有权利或已获授权的 PDF。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

This release candidate concentrates on security and correctness fixes and completes real-system Linux verification:

- Removing a nexPDF watermark can no longer restore a page snapshot recorded before a redaction: any content change invalidates scanned candidates and applying redactions drops the snapshot.
- A failed or cancelled open keeps the previously open document usable instead of leaving an empty session behind a stale window.
- Highlights render as translucent yellow and underline/strikeout as red instead of an opaque black block.
- A signed document can be saved again to its Save As copy; PDF permissions are checked per operation (assembly/redaction need modify, annotations need annotate).
- Password parameters use an exclusively-owned, zeroized `SecurePassword`; POSIX saves create the temporary file with `0600`, restore the destination mode, and fsync the file and directory.
- Text search runs in interleaved slices: a new search, an edit, or closing the document abandons the running search, so thousand-page documents no longer starve queued operations.
- The Windows EXE/installer carry version resources; the macOS bundle includes the license and third-party notices; Save As updates the reading-position key and title; document actions stay disabled until a document opens.
- The translation-coverage check now covers the core layer and runs in CI (175 strings, zero missing). Stable tags no longer publish automatically; they require a manual dispatch after the checklist.
- Binary packages now ship the verbatim LGPL-3.0 (and GPL-3.0) texts required for the LGPLv3 Qt runtime, enforced by a publish gate. Linux verification complete: the rc.11 AppImage passed `--version` and a WSLg CJK GUI check on real Ubuntu 24.04.

This is a release candidate, not the Latest production release. Clean-VM smoke tests and macOS spot checks remain gates for v1.0.0. Packages are not code-signed; Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub after downloading, and only process PDFs you own or are authorized to modify.
