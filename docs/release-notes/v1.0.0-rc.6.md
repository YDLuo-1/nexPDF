# nexPDF v1.0.0-rc.6

## 中文

本候选版确认保持三平台发布范围，并将二进制包体积目标由 80 MiB 上调至 90 MiB：实测 82.730 MiB 的 macOS Universal DMG 从此正常通过，而不是靠组成分析豁免；超过目标的包仍须提供非空组成分析，rc.3 的实测记录保留在 `docs/package-size-analysis.md` 中。

`nexPDF --version` 现在显示发布标签：版本字符串由 CMake 生成（`NEXPDF_VERSION`），打包时注入当前标签，本机构建默认显示项目版本。基准测试工具移入 `tests/benchmarks`，仍使用独立构建开关，最终用户包不含测试、基准程序或 `Qt6Test.dll`。

这是候选版，不是 Latest 正式版。完整人工界面检查和性能验收仍是正式 v1.0.0 的前置门槛。发布包不含代码签名，Windows 可能显示 SmartScreen，macOS 可能显示 Gatekeeper 警告；下载后请核对 GitHub 显示的 SHA-256 摘要，并只处理您拥有权利或已获授权的 PDF。

本项目采用 AGPL-3.0-or-later，并大量使用 AI 辅助开发。软件按原样提供，不附带任何担保。nexPDF 与其他同名或近似名称产品无关联。

## English

This release candidate confirms the three-platform release scope and raises the binary package size target from 80 MiB to 90 MiB: the measured 82.730 MiB macOS Universal DMG now passes normally instead of relying on a composition-analysis exception; over-target packages still require a non-empty analysis, and the RC.3 measurements remain in `docs/package-size-analysis.md`.

`nexPDF --version` now reports the release tag: the version string is generated by CMake (`NEXPDF_VERSION`) and injected with the current tag during packaging, while local builds default to the project version. The benchmark tool moved under `tests/benchmarks` behind its own build option; end-user packages contain neither test nor benchmark executables nor `Qt6Test.dll`.

This is a release candidate, not the Latest production release. Full manual UI checks and performance acceptance remain gates for v1.0.0. Packages are not code-signed; Windows SmartScreen and macOS Gatekeeper may warn. Verify the SHA-256 digest shown by GitHub after downloading, and only process PDFs you own or are authorized to modify.

The project is AGPL-3.0-or-later and was developed with substantial AI assistance. It is provided as-is, without warranty. nexPDF is not affiliated with similarly named products.
