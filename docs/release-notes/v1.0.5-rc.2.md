# nexPDF v1.0.5-rc.2

## 中文

第二轮维护修复普通用户密码可解密另存或重设安全设置、禁止复制的 PDF 仍能导入页面，以及快速编辑后立即关闭可能漏掉保存提示的问题。更改 PDF 安全设置现在需要所有者权限；新增“文件 → 使用所有者密码重新打开”，支持免输用户密码的受限 PDF。

缩放、旋转、切换文档或滚动离开预取区域会取消过期的页面和缩略图任务。新增失败导入回归还发现 MuPDF 在编辑提交前删除重做历史；补丁将删除时机移到成功提交，使失败回退保留原历史。完整核心 UBSan 检查还发现并修复 AES 表值左移时的有符号溢出。Qt 保持 6.11.2，MuPDF 保持 1.28.6，四个维护补丁均包含在完整对应源码包中。

验证范围和限制见[第二轮维护记录](https://github.com/YDLuo-1/nexPDF/blob/v1.0.5-rc.2/docs/maintenance-1.0.5-rc.2.md)。这是预发行版，当前稳定版 Latest 保持不变。PDF 权限由阅读器执行，不是防止其他工具提取内容的加密访问控制；渲染取消仍为协作式。实体打印机、macOS 真机和完整高 DPI/输入法验收仍未完成。

## English

This second maintenance candidate requires owner authentication to decrypt or replace PDF security settings, checks source copy permission before importing pages, and includes queued edits in the close/open save prompt. File → Reopen with owner password also supports restricted PDFs with an empty user password.

Canvas and thumbnail requests are cancelled when invalidated or outside the viewport prefetch range. A regression exposed MuPDF discarding redo history before an edit committed; the journal patch now preserves history when a partial edit is abandoned. Full core UBSan checks also exposed signed AES table shifts, now corrected to unsigned arithmetic. Qt remains 6.11.2 and MuPDF 1.28.6. All four maintenance patches are included in the full corresponding-source archive.

See the [second-pass report](https://github.com/YDLuo-1/nexPDF/blob/v1.0.5-rc.2/docs/maintenance-1.0.5-rc.2.md). This is a prerelease; stable Latest is unchanged. PDF permission enforcement relies on reader cooperation, and render cancellation remains cooperative. Physical printers, macOS hardware and the full high-DPI/input-method matrix remain outside this acceptance scope.
