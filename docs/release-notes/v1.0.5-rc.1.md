# nexPDF v1.0.5-rc.1

## 中文

此维护候选版修复了连续加密保存可能崩溃、保存后撤销状态错误、长文档搜索离开工作线程、匿名水印批量删除错位，以及复制/打印权限未完整执行的问题。保存使用独立 PDF 对象图，保留书签、表单和元数据；失败保存保留编辑状态与撤销历史。Windows 当前打开的源文件可安全原子替换。

打印增加取消、等待超时和文档变化中止；低分辨率权限限制为不超过 150 DPI。渲染请求均返回终态，修复瓦片重试数据并限制并发及单次图像分配。视口绘制不再扩展到整个文档。另修复长崩溃路径的缓冲区溢出与密码擦除。

MuPDF 升至 1.28.6，包含上游近期解析、字体、图像处理修复及 brotli 更新；Qt 保持 6.11.2。补充保存/权限/搜索/取消/打印回归和 ASan/UBSan fuzz 冒烟。详见[维护验收记录](https://github.com/YDLuo-1/nexPDF/blob/v1.0.5-rc.1/docs/maintenance-1.0.5.md)。

本版是预发行版，保留当前稳定版 Latest。打印到 PDF 的自动测试不等同于实体打印机验收；macOS 仍为 CI 验证。取消为协作机制，无法强制打断所有原生解析或驱动调用。保存完整对象图会增加临时内存。包未签名，Windows/macOS 可能显示 SmartScreen/Gatekeeper 提示；请核对 GitHub 附件摘要。AGPL-3.0-or-later，AI 辅助开发，按原样提供。

## English

This maintenance candidate fixes crashes during repeated encrypted saves, saved undo-state tracking, sliced search leaving the document thread, incorrect anonymous-watermark batch removal, and incomplete copy/print permission enforcement. A disposable complete PDF graph preserves catalog data, forms, outlines and metadata without mutating the live undo journal. Failed saves retain edit state; Windows can atomically replace the open source file.

Printing gains cancellation, a bounded wait and document-change cancellation; low-resolution permission caps output at 150 DPI. Every render request returns a terminal result, tile retry state is preserved, raster concurrency and image allocation are bounded, and viewport painting no longer spans the full document. Long crash-path overflow and password erasure are also corrected.

MuPDF is updated to 1.28.6 with upstream parser, font, image and brotli fixes; Qt remains 6.11.2. Regression and instrumented ASan/UBSan fuzz checks are added. See the [maintenance report](https://github.com/YDLuo-1/nexPDF/blob/v1.0.5-rc.1/docs/maintenance-1.0.5.md).

This is a prerelease, retaining the current stable Latest. PDF-printer automation does not establish physical-printer acceptance; macOS remains CI-only. Native cancellation is cooperative, and cloning the save graph adds temporary memory. Packages are unsigned; SmartScreen/Gatekeeper prompts may appear. Verify GitHub asset digests. AGPL-3.0-or-later, AI-assisted development, provided as-is.
