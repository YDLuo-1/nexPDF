# nexPDF v1.0.4

## 中文

新增打印：文件菜单"打印…"（Ctrl+P）支持页面范围选择，按打印机分辨率（上限 300dpi）渲染后等比居中输出。

验证范围（如实说明）：打印路径经编译、现有全部测试与对话框/菜单集成验证，未做实体打印机输出验证。macOS 仍为仅 CI 验证（同 v1.0.2 披露）。发布包不含代码签名，请核对 GitHub 显示的 SHA-256 摘要。AGPL-3.0-or-later，AI 辅助开发，按原样提供。

## English

Printing: "Print…" (Ctrl+P) in the File menu with a page-range dialog; pages render at printer resolution (capped at 300 dpi) and print centered to fit.

Verification scope, stated honestly: the print path is verified by compilation, the full existing test suite, and menu/dialog integration; physical printer output was not tested. macOS remains CI-verified only, as disclosed in v1.0.2. Packages are not code-signed; verify the SHA-256 digest shown by GitHub. AGPL-3.0-or-later, AI-assisted development, provided as-is.
